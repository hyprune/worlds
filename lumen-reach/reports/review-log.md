# Sun Court iteration record

The first remote render was too sparse: flat triangular backdrop, unarticulated
facade, chunky leaf clusters and a foreground lamp hiding the globe. The next
passes add an original generated watershed painting on opaque silhouette cards,
a sky sphere, smaller individual leaves, facade ribs and a physical entry canopy.
Camera sightlines move the lamp/tree away from the primary composition.

The first clearance audit failed on an incorrect world/local quaternion
conversion. Correct conversion maps the screen's local +Z onto its real physical
front. Subsequent sweeps caught stairs/guardrails crossing the field rigs and
bench approach. The rig positions and bench move into the shelter's open floor.

Exported route checks caught a globe path cutting across stair treads, a route
endpoint incorrectly extending a ramp slope onto its landing, and an annex pier
protruding into the rooftop ascent. Routes now turn along actual landing/ramp
centerlines; supports stay beside the walking surface.

The first nested load rejected a tree-obstructed spawn. Arrival moves to clear
paving. The next load exposed the changing core mount adapter's strict area
shape. Area metadata now uses placement-zone IDs; full AABBs stay in the separate
placement namespace. The owner session is never targeted; all trials use core's
verified controller within the shared nested flock.

Current final evidence is written by the milestone verification commands. No
failed frame is delivered as a completed milestone.

# Connected-world iteration record

The later homes add a suspended atrium wall, balconies, a true lower service
descent, cold consoles and maintenance platform, then a snowy communications
basin with a fortress wall, angled bench, diagnostics, dish, masts, cable
gantry, landing ring and walkable operator room. Full-wall clearance checks
forced practicals, pipes, banners and ceiling supports outside usable screen
volumes. Every work home reserves a large independent free-placement volume.

The full route audit exposed overlapping rooftop flights and a final slab
edge that the earlier static floor test missed. The flights are separated,
and the final bridge joins a top-only collision landing at the ramp endpoint.
The static check now includes smaller risers and matches core's capsule bottom
and push-out budget; the real engine traversal remains the acceptance check.

Original alpha steam replaces the opaque ribbon fallback when running core M2.
The daylight watershed uses its full original panorama on the sky sphere.
The night basin has an original opaque mountain card arc and a zenith closure;
its upper image fades into the same paint instead of stretching a row of stars.
A rock ridge hides that sky from the daylight homes. No captured frame is graded.

Texture view accounting showed that full-resolution tiles, large irradiance
atlases and eight captured applications exceeded the total nested-process GPU
budget. Periodic 640px PBR derivatives, separate bounded irradiance atlases,
1536px workspace previews and a 1600px night panorama leave application
headroom without replacing the original masters. Initial live terminal captures used 800×450 buffers; the final application
buffer and capture correction is recorded below.

The stock integration harness reset its state directory after our earlier
assignment, retaining old workspace bindings and covering the static previews
with empty live captures. The release scenario now overrides that reset, uses
a private verified nested state directory and clears only its own layout file.
Owner state and compositor sockets are never addressed.

A final comparison added fuller leaf silhouettes, individual facade service
plates/fixings, captive screen bezel fasteners and cooling slots, plus layered
snow-capped service towers behind the communications facade. They add depth
and maintenance detail outside the reserved work volumes. All window sweeps
and actual route traversals are repeated for the delivered scene.

The combined full-route/tour run completed all 126 graph traversals and 14
flights, then exceeded core's 30-second unused shell launch-grant lifetime.

bootstrap report remains in artifacts for diagnosis. Core's coordinated shell
commit ee66bff changes the visible navigation panel terminology to Overview.

reported fewer than its required 24 rows; primary applications now use 900×600

texture parameters; its regression covers root textures with no mip chain.
The release scenario subsequently captured useful live application content on
